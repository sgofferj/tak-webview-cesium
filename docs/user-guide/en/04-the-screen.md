# Chapter 4 — The Screen

Once signed in, you see the map filling most of the screen. Around it are
a few controls. This chapter gives you the tour.

```
+--------------------------------------------------------------+
|  [Map fills the whole background]                             |
|                                                               |
|  +--------+                                                   |
|  |Sidebar |                                   Status bar:     |
|  | View   |                                   connection,     |
|  | Filter |                                   time, identity, |
|  | Tracks |                                   buttons         |
|  | Staff  |                                   +---------------+
|  +--------+                                   |               |
+--------------------------------------------------------------+
```

## The status bar (bottom of the screen)

A narrow bar with live information and the main controls, from left to
right:

- **Connection indicator** — shows *Connected* when you are online. If it
  says *Disconnected*, see Chapter 13.
- **Pulsing dot** — blinks briefly whenever fresh data arrives. If it is
  moving, data is flowing.
- **Zulu clock** — current time in UTC (`HH:MM:SSZ`). All times in the
  application use Zulu time.
- **Certificate information** — the organization your certificate belongs
  to and its expiry date. The color tells you how much validity remains:
  green = fine, orange = less than a week, red = days. Contact your
  administrator when it turns red.
- **Your identity** — your username, callsign (in your team color) and
  role abbreviation, e.g. `jdoe - BRAVO-1 (TL)`.
- **Location** — opens the menu for setting your own position
  (Chapter 9).
- **Config button** — reopens your identity settings (Chapter 3).
- **Channels button** — manage which channels you listen to and transmit
  on (Chapter 11).
- **Chat toggle** — opens and closes the chat panel; a red badge shows
  the number of unread messages (Chapter 10).
- **Info** — general information about the installation.
- **Logout / Forget** — end your session or wipe your data from this
  device (Chapter 12).

## The sidebar (left edge)

A collapsible panel with four sections:

- **View** — the *Show callsigns* checkbox turns all name labels on/off.
- **Filter** — search box plus affiliation and dimension filters
  (Chapter 7).
- **Active Tracks** — a list of everything currently on the map,
  grouped by category and affiliation (Chapter 7).
- **Staff Comments** — units matching keywords your administrator has
  configured, e.g. all vehicles tagged `#SF` (Chapter 7).

Collapse it with the arrow button on its edge to get more map space.

## Layer picker

The **Layers** button opens a panel over the map where you change base
maps, switch overlays on and off, enable terrain and elevation contours.
See Chapter 8.

## Chat panel

The **chat toggle** slides out a panel with two parts: the channel list on
the left (Rooms and Users) and the conversation view with the message
input on the right. Chapter 10 explains everything.

## Pop-up windows

Several functions open as pop-ups over the map: your identity settings,
channels, overlay styling and an info window. All of them close with their
**Cancel/Close** button or by clicking outside them.

## Your browser's own controls still work

Zooming with `Ctrl` + mouse wheel zooms the whole page, not just the map —
useful if text is too small. `F11` switches full-screen mode, which many
users prefer while operating.
