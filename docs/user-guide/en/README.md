# TAK Web Map — User Guide

A plain-language guide for using the TAK web map viewer. It is written for
operational users — no technical background is needed. If you can use a web
browser, you can use this tool.

## What is this tool?

The TAK web map shows you, on a map in your browser:

- Where the members of your team (and other tracked units) are right now
- Chat rooms and direct messages, shared with everyone on the same network
- Map layers such as satellite imagery, terrain, and your unit's own map data

Everything runs through your unit's TAK server. Your administrator has
already set up the system; you only need your personal credentials.

## Conventions used in this guide

- **Bold** text refers to things you can see or click on the screen, for
  example **Save** or the status bar.
- "Click" also means "tap" if you are using a touchscreen.
- Times shown in the application are Zulu time (UTC), marked with a "Z".
