# TAK-verkkokartta — käyttöopas

Selkokielinen opas TAK-verkkokartan käyttöön. Opas on laadittu
operaatiokäyttäjille — teknistä taustatietoa ei tarvita. Jos osaat käyttää
selainta, osaat käyttää tätä työkalua.

## Mikä tämä työkalu on?

TAK-verkkokartta näyttää selaimessasi kartalla:

- Missä oman joukkueen jäsenet (ja muut seuratut yksiköt) ovat juuri nyt
- Chat-huoneet ja suorat viestit, jaettuina kaikkien samassa verkossa
  olevien kesken
- Karttakerrokset kuten satelliittikuvat, maasto ja oman joukkueen oma
  kartta-aineisto

Kaikki kulkee joukkueenne TAK-palvelimen kautta. Järjestelmänvalvoja on
määrittänyt kaiken valmiiksi; tarvitset vain henkilökohtaiset tunnuksesi.

## Tässä oppaassa käytetyt merkitsemistavat

- **Lihavoitu** teksti viittaa asioihin, jotka näytöllä näkyvät tai joita
  voit napsauttaa, esimerkiksi **Tallenna** tai tilapalkki.
- "Napsauta" tarkoittaa myös "napauta", jos käytät kosketusnäyttöä.
- Sovelluksessa näkyvät ajat ovat Zulu-aikaa (UTC), merkitty päätteellä "Z".
- Sovelluksen valikoiden väri- ja roolivaihtoehdot ovat englanninkielisiä
  (esim. Red, Cyan, Team Lead) — ne ovat verkossa käytettäviä
  virallisia arvoja. Suomenkieliset vastineet kerrotaan opasssa suluissa.

## Kuvakaappaukset

Kuvakaappauksia ei ole tässä versiossa. Järjestelmänvalvojasi voi täydentää
opasta kuvakaappauksilla, jotka esittävät joukkueenne määrittämät
karttakerrokset ja brändäyksen.
