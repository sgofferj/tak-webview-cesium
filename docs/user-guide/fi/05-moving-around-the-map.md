# Luku 5 — Liikkuminen kartalla

## Perusliikkeet (hiiri)

| Toiminto | Miten |
| -------- | ----- |
| Siirrä karttaa | Napsauta ja **vedä** vasemmalla hiirennapilla |
| Lähennä / loitonna | Rullaa hiiren rullaa tai kaksoisnapsauta lähentääksesi |
| Kallista 3D-näkymään | Pidä **oikeaa** hiirennappia (tai `Ctrl` + veto) pohjois-etelä-suunnassa ja vedä |
| Kierrä näkymää | Pidä **oikeaa** hiirennappia ja vedä vasemmalle/oikealle |

Kosketusnäytöllä: yksi sormi siirtää, nipistys zoomaa, kaksi sormea
kiertävät ja kallistavat.

## Nollaa näkymä

**Nollaa näkymä** -nappi palauttaa näkymän suoraan alaspäin katsovaksi,
pohjoiseen suunnatuksi, sopivalta korkeudelta. Käytä sitä aina, kun tunnet
itsesi "eksyneeksi" — se tuo sinut aina puhtaaseen ylhäältäpäin-näkymään.

## Zoomaa kaikkiin

**Zoomaa kaikkiin** sovittaa kaikki tällä hetkellä näkyvät yksiköt yhteen
näkymään. Se jättää ääri-ilmiöt huomiotta (esimerkiksi yksittäisen
yksikön toisella mantereella), ettei karttasi kutistu pallonäkymäksi.

## GoTo-napit

Jos järjestelmänvalvojasi on määrittänyt ne, pikanavigointinapit ilmestyvät
näkyviin paikkojen tai tavoitteiden nimillä (esimerkiksi `CP`, `SATAMA`,
`AMPUMARATA A`). Yksi napsautus lennättää kameran paikalle.

## Yksikön seuraaminen

Napsauta yksikkösymbolia valitaksesi sen; sen infolaatikko avautuu
(luku 6) ja sen viimeaikainen liikerata tulee näkyviin. Valinta seuraa
myös liikkuvia symboleita: yksikön liikeradan tai kurssinuolen
napsauttaminen valitsee itse yksikön.

## Kamerakulman osoitin

**Nollaa näkymä** -nappi toimii samalla osoittimena: kun näkymäsi on
kalteva tai kiertynyt, se näyttää yhden kuvakkeen; kun katsot suoraan alas
ja pohjoinen on ylhäällä, se näyttää toisen. Jos et ole varma kameran
suunnasta, vilkaise kyseistä nappia.
