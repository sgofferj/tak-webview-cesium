# Luku 4 — Näyttö

Kun olet kirjautunut, kartta täyttää suurimman osan näytöstä. Ympärillä on
muutama säätö. Tämä luku esittelee ne.

```
+--------------------------------------------------------------+
|  [Kartta täyttää koko taustan]                                |
|                                                               |
|  +--------+                                                   |
|  |Sivu-   |                                   Tilapalkki:     |
|  |palkki: |                                   yhteys,         |
|  | Näkymä |                                   aika, identiteetti, |
|  | Suodatin|                                  napit           |
|  | Kohteet|                                   +---------------+
|  | Kommentit                                  |
|  +--------+                                   |
+--------------------------------------------------------------+
```

## Tilapalkki (näytön alareunassa)

Kapea palkki, jossa on reaaliaikainen tieto ja päätoiminnot, vasemmalta
oikealle:

- **Yhteysosoitin** — näyttää *Yhdistetty*-tilan ollessasi yhteydessä. Jos
  siinä lukee *Ei yhteyttä*, ks. luku 13.
- **Sykkivä piste** — välähtää lyhyesti aina kun tuoretta dataa saapuu.
  Jos se liikkuu, data virtaa.
- **Zulu-kello** — nykyinen aika UTC:ssä (`HH:MM:SSZ`). Kaikki ajat
  sovelluksessa ovat Zulu-aikaa.
- **Sertifikaattitiedot** — organisaatio, johon sertifikaattisi kuuluu,
  ja sen vanhenemispäivä. Väri kertoo jäljellä olevan voimassaolon:
  vihreä = kunnossa, oranssi = alle viikko, punainen = päiviä. Ota
  yhteyttä järjestelmänvalvojaan, kun tila muuttuu punaiseksi.
- **Identiteettisi** — käyttäjänimesi, kutsimerkkisi (joukkuevärilläsi)
  ja roolilyhenteesi, esim. `jdoe - BRAVO-1 (TL)`.
- **Sijainti** — avaa valikon oman sijaintisi asettamiseen (luku 9).
- **Asetukset** — avaa viestiasetuksesi uudelleen (luku 3).
- **Kanavat** — hallitse, mitkä kanavat kuuntelet ja tavoitat (luku 11).
- **Chat-kytkin** — avaa ja sulkee chat-paneelin; punainen merkki näyttää
  lukemattomien viestien määrän (luku 10).
- **Tiedot** — yleistietoa asennuksesta.
- **Kirjaudu ulos / Unohda** — lopeta istuntosi tai pyyhi tietosi tästä
  laitteesta (luku 12).

## Sivupalkki (vasen reuna)

Supistettava paneeli, jossa on neljä osiota:

- **Näkymä** — *Näytä kutsunimet* -valintaruutu kytkee kaikki nimilabelit
  päälle/pois.
- **Suodatin** — hakukenttä sekä kuuluvuus- ja ulottuvuussuodattimet
  (luku 7).
- **Aktiiviset kohteet** — lista kaikista kartalla tällä hetkellä
  olevista yksiköistä, ryhmiteltyinä kategorian ja kuuluvuuden mukaan
  (luku 7).
- **Henkilöstön kommentit** — yksiköt, jotka vastaavat
  järjestelmänvalvojan määrittämiä avainsanoja, esim. kaikki `#SF`-
  leimatut ajoneuvot (luku 7).

Supista se reunan nuolinapilla saadaksesi lisää karttatilaa.

## Kerrosvalitsin

Kartan reunan **kerrosvalitsin**-nappi (kerrospino-kuvake) avaa paneelin,
jossa vaihdat pohjakarttaa, kytket lisäkerroksia päälle ja pois, otat
maaston ja korkeuskäyrät käyttöön. Ks. luku 8.

## Chat-paneeli

**Chat-kytkin** liu'uttaa esiin paneelin, jossa on kaksi osaa: kanavalista
vasemmalla (**Huoneet** ja **Käyttäjät**) sekä keskustelunäkymä
viestikenttineen oikealla. Luku 10 käsittelee kaiken.

## Ponnahdusikkunat

Useat toiminnot avautuvat ikkunoina kartan päälle: viestiasetukset,
kanavat, lisäkerrosten tyylittely ja tietoikkuna. Kaikki sulkeutuvat
**Peruuta**- tai sulkemisnapista tai napsauttamalla ikkunan ulkopuolelle.

## Selaimen omat toiminnot toimivat edelleen

`Ctrl` + hiiren rulla zoomaa koko sivua, ei vain karttaa — hyödyllistä,
jos teksti on liian pientä. `F11` vaihtaa koko näytön tilaan, minkä monet
käyttäjät suosivat operoidessaan.
